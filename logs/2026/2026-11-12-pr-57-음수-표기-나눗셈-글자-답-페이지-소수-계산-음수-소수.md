### 1. 이번 변경에서 해결한 것

**문제**
추가된 문법 - **음수 직접 쓰기**: `-5`, `x = -1000`을 이해함. - **음수 나눗셈·나머지**: 새 AMI 연산 `SDiv`/`SRem` (WASM i32.div_s/rem_s, Z3 bvsdiv/bvsrem, JS). 0 나눗셈과 i32::MIN / -1 을 증명으로 막음. 범위 검사는 나누는 수가 0을 포함하지 않아야 통과. - **글자 답**: `-> "A"` 줄은 위치 번호를 돌려주는 u32 규칙으로 증명하고, `Contract::labels`를 페이지 런타임이 글자로 바꿈. 페이지 `save grade = ""`. 다른 규칙이 쓰면 거부(같은 파일/다른 파일 모두). `axiom run`/예시 출력도 글자로 표시. - **페이지 소수 계산**: 같은 자릿수 값끼리 `show price + tax`, `show "x" if price > 10.5`. 숫자는 번역 때, `*`·`/`는 AST에서 자릿수 보정. 표시도 자릿수 반영. 음수 값이 들어간 페이지 계산은 거부(런타임 산술이 0 이상 전용이라). - **음수+소수**: `can be negative with 2 decimals` 규칙·페이지 값. 입력 `-2.5` 지원.
