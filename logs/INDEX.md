## 읽는 법

- **자동 기록**: `generated: auto` — PR에서 자동 생성된 기록. 메타데이터의 `source`에 원본 PR 링크가 있습니다.
- **직접 기록**: `generated: manual` — 손으로 정리한 기록. 기존 프로젝트 자산이 여기에 해당합니다.
- 프로젝트별로 보고 싶으면 `logs/{연도}` 아래 파일 이름을, 검색은 저장소 전체 검색을 쓰면 됩니다.
